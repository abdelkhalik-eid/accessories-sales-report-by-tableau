# 📊 Sales Accessories Report Dashboard

This repository contains the **Sales Accessories Report**, a Tableau dashboard designed to visualize key sales metrics for accessory products.  
The dashboard provides a comprehensive overview of product performance, costs, and order distribution across different categories, quarters, and regions.

---

## 🧩 Dashboard Overview

### 🔹 **1. Product Category Analysis**
- Visualizes **total cost** per product category.
- Top-performing categories:
  - **Robots**
  - **Drones**
  - **Robot Kits**
- Displays comparison of spending and category ranking.

### 🔹 **2. Cost by Quarter**
- Time-series trend showing **final cost** per quarter.
- Covers periods from **2017 Q4** to **2019 Q2**.
- Highlights spending peaks at:
  - **2018 Q1 (≈ 1,051,062)**
  - **2018 Q4 (≈ 1,042,985)**

### 🔹 **3. Summary Metrics**
| Metric | Value |
|--------|--------|
| 💰 **Final Cost** | 6,827,736 |
| 📦 **Quantity** | 55,271 |

### 🔹 **4. Final Cost by Category**
- Treemap visualization showing cost contribution by subcategories.
- Largest contributions from:
  - **Robots (RWW-75, MICR-23K)**
  - **Drones (DTD-7000, DX-145)**

### 🔹 **5. Order Type Breakdown**
- Pie chart comparing **Retail vs Wholesale** orders.
  - **Wholesale**: 2,833 orders  
  - **Retail**: 2,143 orders  

### 🔹 **6. Orders by Country**
- Geographic map displaying cost and quantity distribution.
- Largest order volumes observed in:
  - **Western Europe**
  - **Middle East regions**

---

## 🌍 Data Insights

- **Robots** lead all categories with the highest total cost.
- Sales experienced significant growth from **2017 Q4 to 2018 Q1**, followed by stabilization.
- **Wholesale orders** account for the majority of transactions.
- Certain regions dominate both **order volume** and **total cost**, indicating key markets.

## 🛠️ Tools & Technologies
