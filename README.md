# 📊 Sales Accessories Report Dashboard

This repository contains the **Sales Accessories Report**, a Tableau dashboard designed to visualize key sales metrics for accessory products.  
The dashboard provides a comprehensive overview of product performance, costs, and order distribution across different categories, quarters, and regions.

---

## 🧩 Dashboard Overview

### 🔹 **1. Product Category Analysis**
- Visualizes **total cost** per product category.
- Top-performing categories:
  - **Robots**
  - **Drones**
  - **Robot Kits**
- Displays comparison of spending and category ranking.

### 🔹 **2. Cost by Quarter**
- Time-series trend showing **final cost** per quarter.
